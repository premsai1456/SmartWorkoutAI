# SmartWorkoutAI

AI-powered workout posture correction and exercise tracking system using Python, OpenCV, and MediaPipe.

## Features
- Real-time pose detection
- Exercise recognition
- Rep counting
- Workout posture correction
- Voice feedback
- Progress tracking
- Fitness recommendations
- Dashboard analytics

## Technologies Used
- Python
- OpenCV
- MediaPipe
- Tkinter
- SQLite

## Installation

```bash
git clone https://github.com/premsai1456/project.git
cd project
pip install -r requirements.txt
python app.py
```
